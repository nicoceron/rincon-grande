\eyebrow{Scope of work}\par\vspace{2mm}
{\displayfont\fontsize{25}{28}\selectfont\color{Forest}What is included\par}
\vspace{2mm}
{\sffamily\fontsize{9}{11}\selectfont\color{Burgundy}
  The same package is applied to each destination website: Rincón Grande and The Wild Run.\par}

\vspace{5mm}
\scopeitem{01}{Brand-led design}{Translate the supplied identity into a refined interface: palette, RedRose typography, logo, editorial rhythm, photography treatment and calls to action.}

\scopeitem{02}{Content structure}{Organize each website around its destination, lodge, location, stay, experiences, conservation, gallery and contact or booking journeys.}

\scopeitem{03}{Three languages}{Implement Spanish, English and Portuguese versions with a language selector and page-level metadata for each language.}

\scopeitem{04}{Responsive build}{Adapt the existing Astro project for mobile, tablet and desktop with reusable components, semantic structure and a production build.}

\scopeitem{05}{Technical SEO foundation}{Configure page titles, descriptions, semantic headings, friendly URLs, alt text, sitemap, robots.txt, canonical and hreflang tags, Open Graph and basic lodging structured data for search and social channels.}
